# Team 13 Project 1 Retrospective

## What went well?

The trio completed the project entirely online. We never met in person, but
the collaboration still went well. Shared planning documents, GitHub, and
regularly integrating and testing the work helped us stay coordinated. We
delivered the core Lost & Found Tracker features, including persistent storage,
item management, matching, and a tested command-line interface.

## What was difficult?

Working remotely meant we could not rely on quick in-person conversations to
resolve questions. We had to make decisions and communicate progress clearly
through online tools and project notes. Integrating separate parts also
required attention to shared interfaces and consistent behavior.

## What would the trio improve next time?

We would agree on interfaces and integration checkpoints earlier, keep task
updates consistently current, and test changes together sooner. Those habits
would make remote coordination and integration smoother as the project grows.

## Did the final app meet the original goal?

Yes. The application provides a terminal-based way to record and manage lost
and found items, retain records in SQLite, find possible matches, and mark an
item as returned. The optional stretch features, such as user accounts and
automatic notifications, were outside the essential project goal.
